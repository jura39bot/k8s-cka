# CKA Trainer

PWA to prepare the Certified Kubernetes Administrator exam.

- **5 domains** weighted like the real exam: architecture 25%, workloads 15%, networking 20%, storage 10%, troubleshooting 30%
- **18 lessons**, 54 narrated steps
- **Cheat sheets** with the exact commands to run
- **12 exam tips**
- **60 QCM** with an explanation for every answer
- Progress, streak, accuracy, per-domain tracking
- Offline, installable, progress sync through a private GitHub Gist

## Install
Safari → Share → "Add to Home Screen".

## Build
```bash
python3 build.py
```
Bump `CACHE` in `sw.js` on every index.html change.
